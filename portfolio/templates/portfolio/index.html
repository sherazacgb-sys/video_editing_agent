Video Editing Agent

Research prototype

The problem

Captioning and overlaying a video means learning a timeline editor. The Video Editing Agent replaces the timeline with a chat: upload footage, describe the change, and a LangGraph agent transcribes, captions, places overlays and renders the file.

Hard problems solved

  • What's drawn matches what's reported. One layout pass feeds both rendering and the agent's view of the frame, so it can't describe a caption somewhere it isn't.
  • Concurrent agent writes. Moved off SQLite to Postgres so per-call token accounting stops queueing behind a whole-file write lock.
  • No-signup access, safely. Guest identities own jobs like accounts do, with timed retention that clears video first and chat later.
